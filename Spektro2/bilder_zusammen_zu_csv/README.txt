1. Lege deine 01.tif, 02.tif usw. in den Unterordner bilder.
2. Trage die echten k-Werte der linken Bildraender in k_werte.csv ein.
3. Passe DELTA_K und die Funktion k_zu_nm(k) in auswertung.py an.
4. Installiere: pip install numpy pandas pillow
5. Starte: python auswertung.py
6. Die Datei libs_spektrum.csv enthaelt wavelength,intensity.

WICHTIG: Die mitgelieferten k-Werte und die Funktion sind Platzhalter!
Bei stark unterschiedlichen Belichtungen kann eine Intensitaetsnormalisierung
noetig sein. Fehlende Wellenlaengenbereiche werden nicht erfunden.
